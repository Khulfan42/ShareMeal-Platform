PROJECT OVERVIEW:
ShareMeal is a nationwide smart food redistribution platform connecting restaurants, 
hotels, and catering services with verified charities & relief foundations (Saylani, 
Edhi, Al-Khidmat, etc.) across Pakistan. Features automated food matching, order tracking, 
and MealBot AI.

--------------------------------------------------------------------------------
1. PREREQUISITES
--------------------------------------------------------------------------------
- .NET 8.0 SDK (or Visual Studio 2022 with ASP.NET & web development workload)
  Download free from: https://dotnet.microsoft.com/download/dotnet/8.0

- Database: 
  NO SQL Server setup or manual configuration required!
  The project includes a pre-configured, self-contained SQLite database 
  ('ShareMeal.db') with 38+ verified Pakistani restaurants and charities.
  (If SQL Server script is needed for evaluation, 'ShareMeal_Database.sql' is included).

--------------------------------------------------------------------------------
2. HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------

OPTION A: Using Visual Studio 2022 (Recommended for Windows)
  1. Extract this zip folder.
  2. Double-click "ShareMeal Platform.sln" to open the project in Visual Studio.
  3. Click the green "Play / Run" button (or press F5 / Ctrl+F5).
  4. The browser will automatically open at:
     http://localhost:5556 (or https://localhost:7177)

OPTION B: Using Command Prompt / Terminal / VS Code (Windows, Mac, or Linux)
  1. Open Command Prompt or Terminal inside the extracted "ShareMeal Platform" folder.
  2. Run the following command:
     
     dotnet run --launch-profile http
     
  3. Open your web browser and go to:
     http://localhost:5556
