# ShareMeal Platform - Project Scope

## What is this Project? (Overview)
ShareMeal is a web platform designed to save food from being wasted. It acts as a bridge connecting restaurants with charities and NGOs.

Often, restaurants have clean, untouched surplus food at the end of the day that ends up in the trash. ShareMeal's goal is to allow restaurants to post details of this leftover food, so charities can book it and deliver it to people in need.

## How Does it Work? (Core Features)

The project is divided into 3 main roles:

### 1. Restaurant / Donor 
- Can create an account.
- Can post details of leftover food (e.g., "50 boxes of biryani").
- Can see which charity has accepted their food donation request.
- Has a dashboard to view their total food donation history.

### 2. Charity / NGO
- Can create an account.
- Can visit the "Marketplace" to see all available food listed by different restaurants in the city.
- Can "Claim" or "Book" any available food item.
- Can get the restaurant's address and contact details to pick up the food.

### 3. Admin (System Controller)
- Controls the entire platform.
- Can monitor the total number of registered restaurants and charities.
- Can view all transaction and donation records.
- Keeps the system secure with a private Admin Gate to prevent unauthorized access.

## Technical Features (In Simple Terms)
- **Role-Based System:** Each user has their own specific dashboard. A charity cannot access the restaurant panel, and vice versa.
- **Marketplace:** A live screen where all available food donations are listed for charities to see.
- **Easy UI:** The website has a modern and professional design (Dark Theme with Green & Orange accents) making it easy and enjoyable to use.
- **Security:** The Admin panel is totally private, ensuring only authorized personnel have access.

## the Main Goal of the Project
- **Zero Waste:** To prevent good food from ending up in the trash.
- **Social Good:** To reduce hunger by feeding the poor and needy.
- **Easy Bridge:** To provide a simple platform that brings food donors and food receivers together in one place.

*Note: This system is specifically designed as a Final Year Project (FYP) and is in perfectly working condition.*
